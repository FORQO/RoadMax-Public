# RoadMax 2.4.0 — быстрый старт

Windows 10/11 x64 · macOS 13 или новее, Apple Silicon и Intel · 18 ноября 2026

## Запуск и обновление

При обновлении сначала сохраните работу, выберите «Файл» → «Создать резервную копию…» и завершите RoadMax.

- **Windows.** Скачайте и запустите [RoadMax Portable для Windows x64](https://github.com/FORQO/RoadMax-Public/releases/download/v2.4.0/RoadMax-Portable-2.4.0.exe).
- **Mac.** Откройте меню Apple → «Об этом Mac». Для чипа Apple серии M скачайте [DMG для Apple Silicon](https://github.com/FORQO/RoadMax-Public/releases/download/v2.4.0/RoadMax-2.4.0-macOS-arm64.dmg), для процессора Intel — [DMG для Intel](https://github.com/FORQO/RoadMax-Public/releases/download/v2.4.0/RoadMax-2.4.0-macOS-x64.dmg). Откройте образ, перенесите RoadMax в «Программы» и запустите приложение оттуда.

Внутренняя папка данных в Windows — `%APPDATA%\Flowboard\boards`, на Mac — `~/Library/Application Support/Flowboard/boards`. Её можно открыть в самом RoadMax через «Файл» → «Открыть папку данных». Для переноса одной доски выберите «Файл» → «Сохранить проект в папку…». Скопируйте всю папку с файлом `.roadmax` и вложениями, затем на другом компьютере выберите «Файл» → «Открыть проект RoadMax…».

## Язык интерфейса

При первом запуске RoadMax выбирает русский или английский по списку языков системы. Если в списке нет ни одного из них, открывается английский интерфейс. Чтобы сменить язык, откройте меню «Язык» (Language), выберите «Русский» или English и подтвердите перезапуск. Для возврата к настройкам системы выберите «Как в системе».

## Проект как папка

В меню «Файл» выберите «Показать папку текущего проекта». По умолчанию она находится в папке «Документы» → `RoadMax/Projects`. Файл `Project.roadmax` описывает проект. В `Boards` хранятся модели досок со стикерами, связями и координатами. Рабочие файлы находятся в `Files/Название доски`, исходные вложения — в `Attachments/Originals`. При совпадении имён программа добавляет номер.

Правки в RoadMax обновляют рабочий файл. Если вы изменили его в Word или Excel, RoadMax сохранит внешние изменения и при следующем сохранении из приложения создаст соседнюю копию. Чтобы использовать внешнюю редакцию на доске, добавьте этот файл в RoadMax.

Чтобы перенести проект, закройте RoadMax, скопируйте папку целиком и на другом компьютере выберите «Файл» → «Открыть папку проекта RoadMax…». Эта команда работает и после перемещения папки. Если хотите выбрать расположение в самой программе, откройте «Файл» → «Выбрать расположение папки проекта…».

## Найти фразу и сохранить цитату

Откройте нужный проект или папку в библиотеке и введите фразу в поле «Поиск досок и содержимого». В результатах появятся имя документа, отрывок и страница PDF или абзац DOCX. Нажмите «Открыть фрагмент →». Текстовые PDF и DOCX индексируются автоматически. Для сканированных страниц включите «Распознавать сканы (OCR)». На новом профиле эта настройка выключена. Программа распознаёт печатный русский и английский текст локально. Для защищённых документов учитываются разрешения на извлечение текста.

В PDF с текстовым слоем выделите предложение и нажмите «Цитата на доску». На карточке появится ссылка на документ и номер страницы. Кнопка «Рядом с доской» позволяет работать с доской при открытом PDF.

## Доска и навигация

Нажмите «Настройки сетки» в верхней панели и выберите «Линии», «Точки» или «Без сетки». Наведите указатель на нужную часть доски и измените масштаб. Линии и точки следуют за объектами, а дополнительные деления появляются постепенно.

В Dashboard создайте доску или откройте существующую. Слева — проекты, избранное и недавние доски; поиск работает по названиям. На доске выберите инструмент для текста, стикера, карточки, фигуры, стрелки, рисунка, папки или файла.

| Действие | Windows | Mac |
| --- | --- | --- |
| Масштаб около указателя | Колесо мыши | Щипок на трекпаде или Control + прокрутка |
| Перемещение вида | Пробел + перетаскивание | Прокрутка двумя пальцами или пробел + перетаскивание |
| Показать всё / выделение / 100% | 1 / 2 / 0 | 1 / 2 / 0 |
| Дополнить выделение | Shift + щелчок | Shift + щелчок |
| Дублировать | Ctrl+D | ⌘D |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z | ⌘Z / ⇧⌘Z |
| Сохранить | Ctrl+S | ⌘S |
| Справка | F1 или ? | ? |

Сочетания редакторов текста имеют свой контекст. После открытия файла используйте его собственные инструменты и Undo/Redo.

## Файлы внутри RoadMax

Выберите карточку изображения, таблицы или DOCX и нажмите пробел для просмотра. Escape или пробел закрывает быстрый просмотр. Двойной щелчок по карточке открывает полноценный редактор; доступ работает и из папки объектов. Кнопка «Оригинал» сохраняет исходный файл без изменения байтов.

Изображения: поворот/отражение, обрезка, пометки, выбор и изменение текста. Колесо — масштаб, рука — перемещение, двойной щелчок — вписать. Сохранённые правки остаются в проекте. Экспорт копии: PNG/JPEG/WebP; для JPEG явно выберите фон. Для анимации, TIFF и SVG перед редактированием показано, какая часть или растровая версия будет сохранена.

Таблицы: переключайте листы, вводите значения или формулы, выделяйте диапазоны, копируйте и вставляйте, используйте контекстное меню строк/столбцов, сортировку и фильтры. Для CSV/TSV подтвердите экспорт только текущего листа значениями. Активный фильтр XLSX требует подтверждения экспорта без критериев. Оригинал доступен отдельно.

DOCX: форматируйте текст, вставляйте таблицы, ссылки и PNG/JPEG, используйте поиск Ctrl+F. Экспорт DOCX создаёт копию документа, PDF — полный макет всех страниц. Сложные документы могут быть доступны только для просмотра/оригинала; при необходимости преобразуйте копию внешним редактором.

PDF: поиск требует текстовый слой. Для временной руки удерживайте пробел; двойной щелчок вписывает документ во всех инструментах. Доступны пометки, операции с выбранными страницами и экспорт. Скан с печатным русским или английским текстом можно искать из библиотеки проекта.

## Передать доску для просмотра

1. Выберите «Файл» → «Экспорт интерактивного HTML…». Та же команда доступна в панели областей.
2. Укажите всю доску, выделенные объекты или именованную область. В область попадут объекты, которые помещаются в неё целиком. Проверьте количество объектов перед сохранением.
3. Отметьте исходные вложения, которые нужны получателю. По умолчанию в HTML останутся только их карточки. Чтобы получатель открыл источник цитаты, включите карточку PDF в ту же область и отметьте его оригинал.
4. Выберите место для HTML и откройте файл в браузере. Перетаскивание перемещает вид, колесо или щипок меняют масштаб. Кнопка «Вписать» возвращает общий вид. При работе с клавиатурой используйте стрелки, `+`, `−` и `Home`.

В [учебном проекте с PDF](https://github.com/FORQO/RoadMax-Public/raw/c14cd882f7a3f6a7f166b4e3315a1a7a7ea2bd24/examples/north-quay-quote-2.4.0.zip) выберите ссылку на жёлтом стикере. Она ведёт к замечанию на странице 2. Для работы в приложении распакуйте весь ZIP и откройте файл `.roadmax` рядом с папкой `Attachments`.

## Сохранение и ограничения

Следите за статусом сохранения. При ошибке записи свежие изменения остаются в редакторе: освободите место или устраните причину и повторите сохранение. Не закрывайте приложение, пока оно сообщает об ошибке.

Оригиналы не заменяются рабочими копиями. История Undo/Redo редактора действует в пределах текущего открытия; рабочие изменения сохраняются постоянно. Нет облачной синхронизации и совместного редактирования. EXE без цифровой подписи; автоматического обновления нет.

Изображения: до 64 МБ, 24 Мп, сторона до 12 000. Office: вход до 24 МБ. Таблицы: до 30 листов, 5000 строк, 256 столбцов, 100 000 заполненных ячеек и 1,5 млн ячеек плотного представления. DOCX: до 5000 абзацев, 100 изображений, 48 Мп суммарно; PDF-экспорт — до 200 страниц.

Если нужна помощь, укажите версию приложения и операционной системы и опишите шаги, после которых возникает проблема. [Сообщить об ошибке или задать вопрос](https://github.com/FORQO/RoadMax-Public/issues/new/choose).

## Управление связями

Перемещайте объекты через автоматические стрелки, чтобы увидеть обход во время движения. Правый клик открывает меню со свойствами. Лупа ищет объекты на текущей доске.
