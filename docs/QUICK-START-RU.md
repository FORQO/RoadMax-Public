# RoadMax 1.5.0 — быстрый старт

Windows x64 · Portable · 2 ноября 2026

## Запуск и обновление

Скачайте RoadMax-Portable-1.5.0-Windows-x64.exe из официального релиза FORQO/RoadMax-Public. Установка не нужна. Перед запуском закройте старый экземпляр RoadMax. Сохраните backup через меню «Файл», если обновляете существующее рабочее пространство.

Данные: %APPDATA%\Flowboard\boards. EXE можно перемещать, но доски не переносятся вместе с ним автоматически. Для другого компьютера используйте экспорт проекта или резервную копию. Один проект переносится целой папкой: .roadmax и соседний каталог вложений.

## Доска и навигация

В Dashboard создайте доску или откройте существующую. Слева — проекты, избранное и недавние доски; поиск работает по названиям. На доске выберите инструмент для текста, стикера, карточки, фигуры, стрелки, рисунка, папки или файла.

| Действие | Управление |
| --- | --- |
| Масштаб около указателя | Колесо |
| Перемещение вида | Пробел + перетаскивание |
| Показать всё / выделение / 100% | 1 / 2 / 0 |
| Дополнить выделение | Shift + щелчок |
| Дублировать | Ctrl+D |
| Отменить / повторить | Ctrl+Z / Ctrl+Y или Ctrl+Shift+Z |
| Сохранить | Ctrl+S |
| Справка | F1 или ? |

Сочетания редакторов текста имеют свой контекст. После открытия файла используйте его собственные инструменты и Undo/Redo.

## Файлы внутри RoadMax

Выберите карточку изображения, таблицы или DOCX и нажмите пробел для просмотра. Escape или пробел закрывает быстрый просмотр. Двойной щелчок по карточке открывает полноценный редактор; доступ работает и из папки объектов. Кнопка «Оригинал» сохраняет исходный файл без изменения байтов.

Изображения: поворот/отражение, обрезка, пометки, выбор и изменение текста. Колесо — масштаб, рука — перемещение, двойной щелчок — вписать. Сохранённые правки остаются в проекте. Экспорт копии: PNG/JPEG/WebP; для JPEG явно выберите фон. Для анимации, TIFF и SVG перед редактированием показано, какая часть или растровая версия будет сохранена.

Таблицы: переключайте листы, вводите значения или формулы, выделяйте диапазоны, копируйте и вставляйте, используйте контекстное меню строк/столбцов, сортировку и фильтры. Для CSV/TSV подтвердите экспорт только текущего листа значениями. Активный фильтр XLSX требует подтверждения экспорта без критериев. Оригинал доступен отдельно.

DOCX: форматируйте текст, вставляйте таблицы, ссылки и PNG/JPEG, используйте поиск Ctrl+F. Экспорт DOCX создаёт копию документа, PDF — полный макет всех страниц. Сложные документы могут быть доступны только для просмотра/оригинала; при необходимости преобразуйте копию внешним редактором.

PDF: поиск требует текстовый слой. Для временной руки удерживайте пробел; двойной щелчок вписывает документ во всех инструментах. Доступны пометки, операции с выбранными страницами и экспорт. Распознавания сканов (OCR) нет.

## Сохранение и ограничения

Следите за статусом сохранения. При ошибке записи свежие изменения остаются в редакторе: освободите место или устраните причину и повторите сохранение. Не закрывайте приложение, пока оно сообщает об ошибке.

Оригиналы не заменяются рабочими копиями. История Undo/Redo редактора действует в пределах текущего открытия; рабочие изменения сохраняются постоянно. Нет облачной синхронизации и совместного редактирования. EXE без цифровой подписи; автоматического обновления нет.

Изображения: до 64 МБ, 24 Мп, сторона до 12 000. Office: вход до 24 МБ. Таблицы: до 30 листов, 5000 строк, 256 столбцов, 100 000 заполненных ячеек и 1,5 млн ячеек плотного представления. DOCX: до 5000 абзацев, 100 изображений, 48 Мп суммарно; PDF-экспорт — до 200 страниц.
